# 示例：泡泡玛特的生意如何运转

> 历史教学案例，资料截止 2026 年上半年，非当前公司评价或投资建议。金额为人民币。本例只演示部分研究，未完成估值，也不提出买卖动作。

## 当前判断

截至研究时点，泡泡玛特不只是销售单个热门角色：多个 IP 都贡献了收入，公司也组织设计、供应和销售。但仅凭这些结果，还不能确定公司能否长期持续推出成功 IP。

## 先看生意

**产品。** 泡泡玛特销售与角色 IP 相关的毛绒玩具、手办等商品。2026 年上半年毛绒玩具收入 98.25 亿元，占收入 57.2%；手办收入 51.92 亿元，占 30.2%。这说明当期产品收入集中于毛绒品类，但不能单凭占比断言该品类将衰退。[来源：2026 年中期业绩公告，第 31 页](https://www1.hkexnews.hk/listedco/listconews/sehk/2026/0820/2026082000353.pdf)

**渠道。** 公司通过零售店、线上平台、机器人商店和批发等渠道销售。不同渠道承担的租金、人员、平台费用和库存责任不同，因此收入增长不自动等于利润同比增长。[来源：2026 年中期业绩公告](https://www1.hkexnews.hk/listedco/listconews/sehk/2026/0820/2026082000353.pdf)

**制造与交付。** 公司在 2025 年报中披露，供应商主要包括中国的第三方制造商。外部制造有助于组织产能，但公司仍须管理采购、质量和库存；外包不意味着库存风险消失。[来源：2025 年报，报告第 50 页](https://www1.hkexnews.hk/listedco/listconews/sehk/2026/0421/2026042100394.pdf)

## 从事实提出问题

消费者可能因为喜欢某个角色、收藏体验或产品外观而购买。公司则通过产品化、渠道和供应组织获得销售收入；这些动机与机制仍需用消费者研究及更多经营数据验证。

决定性问题：**多 IP 销售反映了公司可重复的能力，还是几个角色与当期潮流共同带来的结果？**

- **解释 A**：公司选择角色、开发产品并利用渠道推广，能让不同 IP 反复获得商业成功。
- **解释 B**：收入主要来自少数受欢迎角色和流行产品形态，公司能力存在，但持续成功仍高度依赖创作者及潮流。

## 证据能支持什么

2026 年上半年，THE MONSTERS 收入约 44.54 亿元，较上年同期约 48.14 亿元下降；Twinkle Twinkle 收入约 26.50 亿元，上年同期约 3.89 亿元；其他多个 IP 也有收入。这支持“公司当期收入并非只来自一个 IP”，但不能证明用户会从一个 IP 转向另一个，也不能证明新 IP 在较长周期内持续成功。[来源：2026 年中期业绩公告，第 30 页](https://www1.hkexnews.hk/listedco/listconews/sehk/2026/0820/2026082000353.pdf)

## 值得继续研究的风险与反证

毛绒收入占比较高。如果该品类需求下降、其他品类无法承接，公司收入和库存周转可能承压；这是有当期产品结构依据的条件判断，并非说需求下降已经发生。可继续观察不同品类的销售、库存变化和折扣情况，同时检查其他 IP 或品类能否承接。

还需研究较长时间内新旧 IP 的表现、用户跨 IP 购买情况、失败项目的成本及相关授权期限。这些信息不足会限制我们判断公司能力的持久性，并不自动证明公司没有优势。

## 示例 Profile

- **公司与期间**：泡泡玛特（09992.HK）；数据截至 2026 年上半年。
- **商业模式**：围绕角色 IP 组织产品设计、外部制造和多渠道销售。
- **当前判断**：多个 IP 对当期收入有贡献；长期可重复成功的能力仍需检验。
- **关键风险**：毛绒占比较高，需求变化可能影响收入与库存；需结合后续数据验证。
- **财务、治理、估值**：本例未完成专题研究。
- **下一步**：核对跨周期 IP 表现、用户购买行为及库存变化。
