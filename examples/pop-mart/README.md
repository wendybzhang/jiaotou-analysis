# 泡泡玛特公司研究 Demo

> 本示例以公司 2025 年报和 2026 年上半年业绩公告为资料，展示如何使用夹头分析框架。股权图使用 2025 年末数据；经营数据为 2026 年上半年。它不是最新公司评价，也不包含完整三表重建和独立估值，不构成买卖建议。

## 一、先说结论

截至本例研究时点，泡泡玛特的生意不只是制造和销售玩具。它围绕角色 IP（具有商业价值的角色形象），组织产品设计、第三方制造和销售渠道，让消费者为喜欢的角色及产品体验付费。

公司有多个 IP 贡献收入，也建立了多种销售渠道，说明它并非只靠一个角色赚钱。但多个 IP 的当期成功，**还不足以证明公司能长期、稳定地培养下一个成功 IP**。毛绒品类占比较高，海外不同渠道的表现也出现分化；判断优势的耐久性，需要继续追踪产品、渠道和现金流。

这是依据有限资料形成的初步判断，不是对公司价值或股价的结论。

## 二、公司是谁，股东买到什么

泡泡玛特国际集团有限公司在香港上市，股票代码为 09992。集团从事潮流玩具的产品设计、开发和销售。[2025 年报，财务报表附注](https://www1.hkexnews.hk/listedco/listconews/sehk/2026/0421/2026042100394.pdf)

2025 年末，GWF Holding 直接持有上市公司 41.78%；王宁相关持股实体还包括 Tianjin Paqu 和 Pop Mart Hehuo。具体信托、持股实体、比例及计算口径见[股权结构图与管理层专题](ownership-management.md)。该图不是完整集团子公司清单，也不能当成最新股权结构。

## 三、商业模式：先看清生意

### 1. 产品：客户为什么买

公司销售与角色 IP 相关的毛绒玩具、手办等。2026 年上半年，毛绒玩具收入约 98.25 亿元，占收入的 57.2%；手办约 51.92 亿元，占 30.2%。[2026 年中期业绩公告，第 31 页](https://www1.hkexnews.hk/listedco/listconews/sehk/2026/0820/2026082000353.pdf)

消费者可能因为喜欢角色形象、收藏体验、装饰或社交表达而购买。这些是解释购买行为的**假设**，还需要消费者访谈和购买数据验证。不同消费者可能有不同动机，不能把一次购买直接理解成对泡泡玛特母品牌的忠诚。

### 2. 渠道：产品怎样到达客户

公司使用门店、机器人商店、线上和批发等渠道。2026 年上半年，中国业务的零售店销售收入约 60.90 亿元，线上销售收入约 47.79 亿元；这两个数字属于公司公告中的中国业务口径，不是全球合计。[中期业绩公告，第 25—26 页](https://www1.hkexnews.hk/listedco/listconews/sehk/2026/0820/2026082000353.pdf)

门店可以让消费者看到和体验商品，但需要承担租金、装修和人员费用；线上可以触达更多客户，但成交可能受到平台流量与营销投入影响。**收入增长不自动等于单店盈利改善或获客成本下降**，需要进一步查看成熟门店和渠道费用数据。

### 3. 制造与交付：收入怎样变成现金

2025 年报披露，公司供应商主要包括中国的第三方制造商。公司需要组织产品开发、采购和销售，并管理质量及库存。[2025 年报，第 50 页](https://www1.hkexnews.hk/listedco/listconews/sehk/2026/0421/2026042100394.pdf)

外部制造可以帮助公司组织产能，但不会自动消除采购预测错误的后果：如果产品卖得慢，库存可能占用现金，最终需要折价销售。这里说的是经营机制，并非断言某批库存已经发生损失。

### 4. 把生意连起来

角色吸引消费者 → 公司设计并组织生产商品 → 门店和线上渠道让商品被发现和购买 → 销售扣除产品、渠道及运营成本后形成利润与现金 → 公司再把资源投入产品、渠道或回报股东。

这条链条能否反复成立，取决于角色吸引力、产品开发、供应和渠道是否能持续配合。多个环节同时存在，不等于已经证明它们形成自我强化的飞轮。

## 四、决定性问题：公司能力还是单次风口？

**问题：泡泡玛特能否持续把不同角色开发成受欢迎的商品，而不只是依赖少数热门 IP 或某一种流行品类？**

- **解释 A：有可重复的组织能力。** 公司在角色选择、产品设计、供应和渠道方面积累了经验，能帮助不同 IP 获得商业成功。
- **解释 B：成功更依赖创作者与潮流。** 公司有商业化能力，但多个角色可能同时受益于同一轮潮流；潮流过去后，收入和利润未必能持续。

2026 年上半年 THE MONSTERS 收入约 44.54 亿元，低于上年同期约 48.14 亿元；Twinkle Twinkle 收入约 26.50 亿元，上年同期约 3.89 亿元。CRYBABY、DIMOO 等也有收入。这些事实支持“当期不是只有一个 IP 在赚钱”，但**不能直接证明同一批用户跨 IP 购买，也不能证明新品长期成功率**。[中期业绩公告，第 30 页](https://www1.hkexnews.hk/listedco/listconews/sehk/2026/0820/2026082000353.pdf)

下一步应看较长期间不同 IP 的销售生命周期、失败产品成本、用户跨 IP 购买情况和授权期限。如果新 IP 多次独立成长、老 IP 降温时其他产品能够接续，将更支持解释 A；如果多个 IP 同时随一种潮流退去，则解释 B 更值得重视。

## 五、优势、弱点与仍需验证的地方

**可能的优势：** 公司已有多 IP 商品化、产品设计和多渠道销售的经营基础。多个 IP 在同一期间贡献收入，说明公司不只是售卖单一角色。但仅凭这些事实，还不能判断优势的强度、竞争对手复制成本或长期持续时间。

**经营弱点与约束：** 一方面，毛绒品类占收入超过一半，收入结构对这一产品形态的需求变化较敏感；另一方面，不同渠道并非同步增长。2026 年上半年，美洲线下收入同比增长 19.5%，线上收入同比下降 45.6%。因此，不能简单说“美洲所有渠道都在衰退”，也不能只凭线下增长认定整体增长稳固。[中期业绩公告，第 28 页](https://www1.hkexnews.hk/listedco/listconews/sehk/2026/0820/2026082000353.pdf)

## 六、管理层与资本配置

2026 年上半年，王宁同时担任董事长和 CEO。董事会认为这种安排有利于领导及战略规划的一致性；这是公司的解释，并不单独证明监督有效或失效。[中期业绩公告，第 42 页](https://www1.hkexnews.hk/listedco/listconews/sehk/2026/0820/2026082000353.pdf)

同期公司回购 1,122 万股，支付约 17.44 亿港元，之后注销。注销会减少股份数量，但要判断回购是否划算，还需要独立估值、资金来源和其他用途的信息，本例尚未完成。[中期业绩公告，第 43 页](https://www1.hkexnews.hk/listedco/listconews/sehk/2026/0820/2026082000353.pdf)

更多股权关系、资料时点与管理层判断，见[股权结构与管理层专题](ownership-management.md)。

## 七、风险：哪些事项会改变判断

1. **毛绒需求变化。** 毛绒占当期收入 57.2%。如果需求显著下降、其他品类不能承接，可能影响收入和库存周转。占比高是事实；需求必然下降不是事实。
2. **海外渠道承接。** 美洲线上下降、线下增长，说明渠道表现分化。需要继续看线下增长是否由可持续的门店经济支撑，以及线上下降的原因和持续时间。
3. **IP 权利与续约。** 不同 IP 的权利安排可能不同。未掌握具体条款时，应核查期限、地域及分成；合同未披露本身不证明已经发生不利变化。

这些问题要结合后续证据和缓冲因素继续判断，不因有不确定性就默认生意恶化，也不凭当前热度忽视变化。

## 八、财务线索与研究边界

2026 年上半年，公司收入约 **171.73 亿元**，同比增长 **23.8%**；毛利润约 **119.66 亿元**；归母利润约 **50.38 亿元**。这些是同一半年度的数据，不应直接等同于全年或自由现金流。[中期业绩公告，第 1 页](https://www1.hkexnews.hk/listedco/listconews/sehk/2026/0820/2026082000353.pdf)

本示例**没有完成资产负债表、利润表和现金流量表的系统分析，也没有重建自由现金流**。要进一步评价财务质量，应核对完整财报及附注，再研究利润如何转换为现金、库存与资本投入，以及增长对资金的要求。

## 十、带着问题继续思考

- 你认为消费者更忠于某个角色，还是泡泡玛特本身？需要什么证据才能区分？
- 哪些事实能说明公司有能力持续开发新 IP，而不只是受益于同一轮潮流？
- 如果毛绒需求回落，公司哪些成本可以缩减，哪些现金已被库存和门店占用？
- 如果公司继续增长，需要投入多少资本？这些投入最终为每股股东创造了什么？

使用者可以在此基础上补充新的资料和自己的判断，而不是把这份示例当成固定答案。
