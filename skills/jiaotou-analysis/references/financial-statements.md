# 三表与财务质量

先确定上市主体、行业、期间、币种、合并范围、披露日期和审计状态；优先取官方年报、附注与公告，保留逐项来源。用户可选择近五年、上市至今或指定年份；完整年度、半年与季度分开列示，披露缺口不能填零。

## 简化三表

- **资产负债表**：按经济实质归并资产、经营负债、金融性负债和权益，说明各合并项的原始科目；现金区分受限、运营必需及可能多余部分。资产与负债加权益须勾稽；使用权资产、租赁负债和少数股东单列或说明。金融企业等特殊业务先调整分类。
- **利润表**：按时间列收入、成本、毛利、费用、经营利润、税及归母利润；按真实业务找收入驱动，而非机械套用量价。说明非经常项目及会计政策变化。
- **现金流量表**：分别列经营、投资、筹资现金流及重要明细；列资本开支的具体构成。不能把利润当现金，不能把集团现金流直接视作归母现金。

## 三表联读

以同期间的数据检查利润与经营现金的差异；结合应收、库存、预收、应付和必要投入理解现金占用。正常规模增长不自动等于风险；发现异常先查会计口径、季节、收购、税款时点和商业过程，再提出竞争性解释。用具体数字、来源和假设解释，不凭相关性断言因果。

长期研究保留可核对的原始数字、单位、公式及调整桥，缺失时说明来源和影响，不虚构。专题和长期表放研究底稿，Profile 留简短判断及真实链接。
