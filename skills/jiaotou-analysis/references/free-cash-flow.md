# 自由现金流

先理解公司维持生意需要什么投入，再计算和解释现金。

**基础 FCF = 经营活动现金流（CFO）− 指定口径的资本开支（CapEx）**。列明报表字段、公司、期间、币种、来源和计算；不同会计准则对利息等分类不同。检查营运资金、税款、一时性收支、资本化和会计政策。基础 FCF 不自动等于归母股东可分配现金。

**经营者视角**：从正常经营现金流减维持性资本开支及尚未扣除、维持业务必需的现金支出。逐项解释依据、合理区间、归属与可持续性；维持和扩张的支出通常无法直接从报表区分，缺证据则不伪造精确数值。租赁本金、研发、营运资金等先检查是否已计入，禁止重复扣减；不要把会计折旧再次机械扣除。先处理整体企业与股权现金流及少数股东口径，再接估值。

结合多个年份和商业周期判断常态，区分集团与归母、历史与预测，明确假设及反证。金融企业如不适用一般口径，要说明并选择适用方法。
