# 估值与反向估值

估值必须先理解生意、股权边界和现金流，再选择适合该公司的方法。分别列证据、计算和主观假设；没有可核对的价格、股数、币种、现金流或重要假设时，披露缺口，不伪造结论。估值日期固定，所有币种与汇率可追溯。

明确使用企业自由现金流还是股权自由现金流，折现率和增长口径与之匹配。预测由经营机制驱动：业务量、价格、利润、营运资本、维持和增长投入如何影响归属股东的现金；避免把当期峰值直接外推。列公式、期限、折现率、终值、股数、稀释及每项数据来源。

企业价值到股权价值要检查净债务、租赁、少数股东及非经营资产；股权口径也须解释已计入事项。现金需区分经营必需和多余，资产、现金流、租金及债务各计算一次；避免估值桥重复计算。情景由可解释的经营机制产生，不机械凑乐观悲观；测试关键变量并说明能推翻假设的事实。

反向估值从价格倒推市场要求的未来现金流或增长，说明哪些量是观察数据、哪些是模型假设。多个组合可能匹配同一价格，不能把一个模型隐含值说成市场真实想法。是否买卖由用户结合目标、风险承受能力和其他选择自行决定；不把不完整研究包装成投资建议。
