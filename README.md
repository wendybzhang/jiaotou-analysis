# 夹头分析｜价值投资公司研究助手

一套帮助你理解公司、提出好问题并形成自己判断的 AI 研究框架。它源于作者对芒格、巴菲特、唐朝及其他投资资料的阅读与思考，结合实际公司研究持续迭代。这里提供的是研究方法，不代表上述人物或作者对任何公司的投资建议。

## 适合谁

适合已有基本投资理念，希望更有条理地研究公司、检验判断的投资者。AI 可以整理事实、提出解释和反证；你需要检查来源、理解推理，并自行决定是否接受结论。

## 开始使用

在支持 `SKILL.md` 格式的 AI 助手中，将 `skills/jiaotou-analysis` 文件夹安装到该助手的技能目录，或让助手读取该文件及其引用文件。具体安装目录依工具而异。确保助手可以检索公开资料；没有联网能力时，请提供财报和资料。

```text
请使用夹头分析研究泡泡玛特。
范围：先理解商业模式。
深度：标准。
输出：关键结论、依据、不同解释和轻量 Profile。
```

研究也可以从一个问题开始，例如：“客户为什么持续购买这家公司的产品？”轻量研究、标准研究和专题深挖的区别见技能文件。首次研究不会自动要求完成估值或给出买卖建议。

## 框架包含什么

- 商业模式：产品、渠道、制造或服务交付，以及它们如何形成赚钱能力。
- 风险筛选：识别具体、重要且有依据的经营风险，区分压力测试和已发生事实。
- 轻量 Profile：记录当前判断与来源；研究真正展开后再建立专题。
- 自定义指引：保留、调整或删除问题，逐渐形成自己的研究流程。
- 泡泡玛特历史案例：展示如何用有限资料分析，数据截止 2026 年上半年，不是当前结论。

## 根据自己的方法修改

先用一个熟悉的公司试跑，记录哪些问题改变了你的理解、哪些没有帮助。修改 `references/` 中的研究问题或 `assets/` 中的模板，再用另一家公司检验。不要因为 AI 说得自信就接受结论，也不必沿用本框架对每个问题的判断。

## 资料与边界

优先使用公司公告、年报及监管文件，标明期间、口径和链接；其他资料也应标明来源。研究过程中需区分事实、推断、假设和未知。数据不足时避免虚构，估值和投资动作需要额外资料与独立判断。
