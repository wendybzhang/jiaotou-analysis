# 夹头分析｜看懂公司，形成自己的投资判断

你不需要成为财报专家，也不必只靠别人的研报来理解一家公司。你需要一套好的思考方法，帮助你从纷繁的信息中找到真正重要的问题。

**夹头分析是一套价值投资导向的 AI 公司研究框架。** 它陪你从产品、客户、渠道和经营过程出发，逐步理解公司如何赚钱、优势从哪里来、哪些地方可能变弱，以及一条利空究竟会怎样影响生意。

你仍然可以读别人的分析，也可以借此发现自己遗漏的问题。但最终，你能回到公司本身，理解证据和推理，慢慢形成**属于自己的投资理解与风格**。

## 像一位研究伙伴，陪你一起思考

这套框架受到芒格、巴菲特、唐朝等价值投资思想的启发，也融入了作者在阅读、思考和公司研究中积累的方法。它尝试把这些思想转化成 AI 可以陪你一起追问的具体问题：

- **这家公司做什么生意？** 客户为什么买，为什么愿意再买？收入如何变成利润和现金？
- **它有什么优势和弱点？** 竞争者容易复制哪些部分？公司又依赖哪些自己无法完全控制的条件？
- **一条利空到底伤到了什么？** 是短期波动、某项业务受损，还是长期赚钱能力发生了变化？有哪些证据支持，又有什么缓冲因素？
- **还有什么其他解释？** 一款产品热卖，可能是公司有持续创新能力，也可能恰好赶上潮流。现有证据能区分它们吗？
- **什么会改变我的判断？** 哪些经营数字、后续事实或反面证据值得继续观察？

它不会替芒格或巴菲特发言，也无法代替他们本人或保证投资结果。它借鉴这些思想中的提问方式，让 AI 帮你整理信息、检验逻辑、提出不同解释，而你始终可以追问、质疑并作出自己的决定。

## 从看懂生意开始

研究通常从三个具体的业务环节入手：

1. **产品与客户**：公司卖什么，解决什么需求，客户为什么选择它。
2. **市场与渠道**：产品怎样到达客户，公司和渠道伙伴如何分配收益。
3. **制造与交付**：公司如何生产或提供服务，扩张需要什么资源，会承担哪些成本。

再把这些事实连起来，分析复购、定价、竞争优势、增长和现金流。不同公司值得深挖的问题不同，框架的作用是帮助你找到重点，不是要求每一家公司都回答同一套填空题。

## Skill 的结构与能力

夹头分析由一个入口、六个研究方法模块、一份轻量 Profile 模板和泡泡玛特示例组成。入口根据任务选择相关模块；研究一个具体问题时，不必每次运行全部流程。

```text
夹头分析
├─ Skill 入口：判断任务、范围与研究深度
├─ 研究方法
│  ├─ 商业模式
│  ├─ 股权结构与管理层
│  ├─ 三表与财务质量
│  ├─ 自由现金流
│  ├─ 估值与反向估值
│  └─ 风险筛选
├─ 轻量公司 Profile 模板
└─ 泡泡玛特历史研究示例
```

| 模块 | 可以帮助你做什么 | 使用时要注意 |
| --- | --- | --- |
| **商业模式** | 理解产品、客户、渠道和交付，分析赚钱机制、竞争优势和不同解释。 | 有收入或增长，不自动证明优势能长期持续；需要检验证据和因果关系。 |
| **股权与管理层** | 根据公开资料生成可编辑的股权结构图，研究上市主体、控制权、管理层和资本配置。 | 图中的比例和关系取决于披露日期与资料完整度；持股集中不等于治理失效。 |
| **三表与财务质量** | 整理资产负债表、利润表和现金流量表，按指定期间比较，并分析利润和现金的关系。 | 结果取决于原始数据、会计口径与核对质量；半年和全年数据不能混用。 |
| **自由现金流** | 计算基础 FCF，并分析维持经营所需投入和其他现金支出。 | 维持性投入和正常化现金流常需估算；基础 FCF 不自动等于股东可取得的现金。 |
| **估值与反向估值** | 展示估值公式、假设和敏感变量，从价格倒推可能隐含的经营要求。 | 结果依赖现金流、增长、回报率、价格和股数等假设；不能把估算当成确定价值。 |
| **风险筛选** | 区分事实、正常变化、确定事项和压力假设，研究重要风险怎样影响生意。 | 假设不等于已发生事实；也不能仅因缺少数据就断定风险不存在。 |
| **轻量 Profile** | 记录当前理解、依据、未知和专题链接，方便持续研究。 | 未研究的栏目保留空白或标明未研究，不应为了完整而编造。 |

[泡泡玛特公司研究 Demo](examples/pop-mart/README.md)展示商业模式、风险与 Profile；另有[股权结构图与管理层专题](examples/pop-mart/ownership-management.md)和[三表、自由现金流及历史估值示例](examples/pop-mart/financials-and-valuation.md)。示例使用历史时点资料，不代表当前结论；其中完整三表重建和独立估值尚未完成。

不同 AI 助手、数据获取方式和公司披露情况都可能影响结果；长期三表整理与完整估值尤其需要复核。股权图默认使用 Mermaid，目标环境不支持时可用文字树或表格。

## 它能做什么，不能做什么

夹头分析能帮你：

- 整理公司披露的信息，从产品、渠道和交付理解生意是怎样运转的。
- 提出有依据的初步判断、不同解释和反面问题，帮助你检查自己的想法。
- 分析一项优势或利空可能通过什么途径影响经营，指出目前有证据支持什么、还有什么不知道。
- 记录研究结论和来源，方便你继续追问、复查和更新。

夹头分析不能替你：

- **直接给出可靠的最终答案**：AI 可能遗漏信息、理解错资料，或者把推断说得过于肯定；它的回答需要你核对和质疑。
- **决定哪家公司能投或不能投**：这取决于你对公司的理解、价格、个人目标和风险承受能力。框架可以协助分析，不能代替你作投资决定。
- **自动获得投资判断力**：一个 Skill 可以提供方法和陪伴，但能力需要你自己通过阅读、思考、实践和复盘逐渐积累。

## 开始使用

在支持 `SKILL.md` 格式的 AI 助手中，将 `skills/jiaotou-analysis` 文件夹安装到该助手的技能目录，或让助手读取该文件及其引用文件。具体安装目录依工具而异。确保助手可以检索公开资料；没有联网能力时，请提供财报和资料。

```text
请使用夹头分析研究泡泡玛特。
范围：先理解商业模式。
深度：标准。
输出：关键结论、依据、不同解释和轻量 Profile。
```

也可以从你最想弄清楚的一个问题开始：

```text
这家公司刚出了利空消息。请帮我区分已确认的事实和市场猜测，
分析它可能怎样影响公司的生意，以及还有哪些重要信息尚不清楚。
```

轻量研究、标准研究和专题深挖的区别见 [Skill 说明](skills/jiaotou-analysis/SKILL.md)。首次研究不会自动要求完成估值或给出买卖建议。

## 阅读、思考，把框架变成你的判断力

真正理解一家公司的能力，不是安装一个 Skill 就能获得的。它来自持续阅读、观察和思考：读投资经典，也读公司年报、行业资料和不同观点；遇到不理解或不认同的地方，停下来问自己为什么。

夹头分析可以陪你整理这些输入、联系具体公司、提出问题和反面解释。但更重要的是，先经过你自己的理解和取舍，再把真正有启发的想法加入研究方法。一次研究后也可以回头看：当初的判断哪里对了，哪里错了，原因是什么。

**阅读提供养分，思考形成理解，研究和复盘检验理解。** 随着这个过程不断积累，框架才会逐渐长成你自己的方法，价值投资的判断力也在实践中慢慢沉淀。

### 如何把输入变成自己的研究方法

框架可以从一个小问题开始逐步成长，不需要一次建立完整体系：

1. **记录让你有收获的内容。** 阅读书籍、年报、访谈或其他投资者的分析时，记下来源、原来的观点，以及你自己的理解：它为什么重要？你赞同什么，又有什么疑问？
2. **和 AI 讨论，但由自己取舍。** 把你的笔记或想法交给夹头分析，请它解释、提出反例，并联系一家公司。不要因为 AI 总结得流畅，就直接把观点当成长期规则。
3. **把理解转成可以追问的问题。** 例如，读到“关注管理层如何使用股东的钱”后，可以加入问题：“公司过去把现金用于分红、回购还是扩张？这些选择的结果如何？”保留适用条件和来源，而非只记一句口号。
4. **放进真实研究中试用。** 找一家熟悉的公司，看看这个问题是否帮助你发现了新事实、改变了判断，还是只增加了空话。也试着找会推翻它的例子。
5. **确认后保存，再定期复盘。** 值得长期使用的问题，可以加入你自己的方法文件或 Profile 模板；只适合某个行业、某家公司的观察，则留在相应研究笔记中。后来发现不适用时，继续修改。

例如，你可以这样请 AI 帮忙：

```text
这是我读书后的笔记和自己的理解：……
请帮我讨论它对分析公司有什么启发、适用于什么情况，
并提出反例。再给我一条可以在真实公司中检验的研究问题。
先不要修改我的框架，等我确认后再帮我整理进去。
```

**保存在哪里？** 使用你自己的框架副本：通用研究方法可放进 `skills/jiaotou-analysis/references/` 对应文件；想在每次建档时提醒自己的问题，可调整 `skills/jiaotou-analysis/assets/company-profile.md`。个人阅读笔记和公司资料可以单独保存在你自己的知识库或文件夹里。修改前建议先留一份备份，并记录来源与修改理由。

一次聊天中的输入不会自动成为 Skill 的长期能力。只有把经过自己确认的方法保存到后续使用的框架或资料中，并在下一次研究时让助手读取，它才有机会继续发挥作用。个人资料放在哪里、是否上传到第三方工具，由你自己决定。

## 资料与边界

优先使用公司公告、年报及监管文件，标明期间、口径和链接；其他资料也应标明来源。AI 整理的信息和推断可能出错，需要回到原始资料核对。数据不足时，应明确未知；估值和投资决策还需要价格、个人目标及风险承受能力等更多信息。
